# rl

RL post-training on small models, working up to a custom environment that tests whether a
model's stated reasoning matches what it actually does (CoT faithfulness).

Built on [prime-rl](https://github.com/PrimeIntellect-ai/prime-rl),
[verifiers](https://github.com/PrimeIntellect-ai/verifiers), and
[inspect-ai](https://github.com/UKGovernmentBEIS/inspect_ai).

Failures get logged in [log/failures.md](log/failures.md).
